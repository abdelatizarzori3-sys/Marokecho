## 🚀 التثبيت

### 1. الواجهة الأمامية (GitHub Pages)

```bash
# الملفات في frontend/ يمكن نشرها مباشرة على GitHub Pages
cd frontend
# ارفع الملفات للمستودع
```

### 2. الخادم الخلفي (Flask + Kimi)

```bash
# 1. تثبيت المتطلبات
cd backend
pip install -r requirements.txt

# 2. إضافة مفتاح Kimi API
export KIMI_API_KEY="your-kimi-api-key"
# أو أنشئ ملف .env:
# KIMI_API_KEY=your-key-here

# 3. تشغيل الخادم
python app.py
# يعمل على: http://localhost:5000
```

### 3. الحصول على مفتاح Kimi API

1. ادخل على: https://platform.moonshot.cn
2. سجل حساب جديد
3. احصل على API Key
4. أضفه في المتغير `KIMI_API_KEY`
